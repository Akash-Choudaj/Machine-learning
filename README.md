# Machine Learning From Scratch

A step-by-step journey to learn and implement Machine Learning concepts from the basics to advanced topics using Python.

## 📌 About This Repository

This repository contains my Machine Learning learning journey, including:

- Python libraries used in Machine Learning
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Supervised Learning
- Unsupervised Learning
- Model Evaluation
- Machine Learning algorithms implemented from scratch
- Practical Machine Learning projects

The main goal of this repository is to understand **how Machine Learning algorithms work**.
